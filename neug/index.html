Quick start

From install to first query

NeuG runs where your application runs. Install the library, open a database, and query it with Cypher.

quickstart.py
$ pip install neug

import neug

db = neug.Database("")
conn = db.connect()

result = conn.execute("""
  MATCH (n) RETURN n LIMIT 10
""")
